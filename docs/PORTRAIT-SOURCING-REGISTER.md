# Portrait sourcing register

**Cut-off:** 26 November 2026  
**Scope:** the 38 officeholder profiles (President + 36 governors + FCT Minister) and 18 presidential candidate profiles currently in Sabi.

## Image rules

- Use an image only after confirming that it depicts the correct person and recording the original file page, creator, licence and licence URL.
- Prefer CC0, CC BY, CC BY-SA or explicit written permission. Preserve required attribution and licence links in the UI.
- A public web page, campaign website, newspaper credit or another directory's image does not itself grant Sabi a reuse licence.
- Nigeria's Copyright Act 2022, section 20(1)(d), includes fair dealing for criticism, review or reporting current events, subject to the purpose, nature, amount used and market-effect factors and an acknowledgement where practicable. This is not blanket permission for every profile image; seek permission or an open licence by default and review any fair-dealing use individually.
- Never use AI-generated likenesses or an image that merely resembles the person. Never use an image where the source page's own description identifies a different person.
- If no portrait is cleared, keep the initials placeholder and mark the portrait as being sourced. Do not silently substitute a different politician.
